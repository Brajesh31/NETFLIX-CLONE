# Support

For questions about setup, layout, or documentation, open a GitHub Issue with reproducible details.

Before opening an issue:
1. Read the README and relevant docs.
2. Confirm the issue exists on the current default branch.
3. Run `python scripts/validate_site.py` for missing local asset issues.
4. Search existing issues.

For visual issues, include browser/version, operating system if relevant, viewport dimensions, reproduction steps, expected and actual appearance, and a screenshot with private information removed.

Never include passwords, account credentials, or personal data. Report sensitive vulnerabilities privately according to SECURITY.md.

This is an educational static UI recreation, not official streaming customer support. It does not provide accounts, subscriptions, payments, or streaming.
