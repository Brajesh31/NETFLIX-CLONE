# Security Policy

This repository is a static UI recreation and must not be presented as an official streaming service.

## Reporting

Use GitHub private vulnerability reporting if enabled. Otherwise, contact the repository owner privately through GitHub. Do not publish personal data or sensitive exploit details in public issues.

## Safety requirements

- Do not add deceptive login forms or collect streaming-service credentials.
- Do not add analytics or tracking without transparent disclosure and appropriate consent.
- Do not commit API keys, passwords, or private user data.
- Third-party logos, images, and video files are not covered by the repository's source-code license.
