# Contributing

This repository is a static HTML/CSS learning project.

## Run locally

Open `index.html` in a browser or run:

```bash
python -m http.server 8000
```

## Contribution guidelines

- Keep the implementation static unless a change explicitly adds and documents a backend.
- Preserve the educational, unofficial nature of the project.
- Do not add real sign-in, password collection, payment, or email capture flows.
- Use semantic HTML, meaningful alt text, keyboard-accessible controls, and responsive CSS.
- Do not commit private media, credentials, or generated build output.

## Pull requests

Describe the visual or accessibility change, include before/after screenshots when relevant, and list the browsers and viewport sizes checked.
