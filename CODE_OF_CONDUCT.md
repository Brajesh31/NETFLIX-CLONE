# Code of Conduct

## Our commitment
The project aims to maintain a respectful, constructive environment for people learning and contributing to frontend development. Participation is expected to be professional and considerate regardless of experience level.

## Expected behavior
- Be respectful and patient.
- Give feedback about the work, not personal characteristics.
- Explain technical disagreements with evidence and clear reasoning.
- Accept constructive criticism and reviewer decisions.
- Respect different backgrounds, skill levels, and communication styles.
- Protect private information and obtain permission before sharing another person's work.
- Keep discussions relevant to the repository.

## Unacceptable behavior
- Harassment, discrimination, threats, intimidation, or personal attacks.
- Sexualized or hateful language directed at others.
- Publishing private information without consent.
- Deliberate disruption, spam, or repeated bad-faith behavior.
- Misrepresenting project functionality or impersonating an official service.
- Pressuring contributors to disclose credentials, personal data, or private contact details.

## Reporting
Report conduct concerns privately to the repository owner through GitHub. Do not post sensitive personal details in a public issue. Include relevant links or context where safe to do so.

## Maintainer responsibilities
Maintainers may edit or remove harmful content, close discussions, restrict participation, or take other reasonable action to protect contributors and the project. Decisions should be proportionate to the behavior and focused on safe collaboration.

## Scope
This code applies in repository issues, pull requests, code reviews, project discussions, and other spaces when someone is representing or participating in this project.
