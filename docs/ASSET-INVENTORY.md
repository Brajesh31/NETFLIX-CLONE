## Maintenance
- Preserve exact path casing and update every reference when replacing an asset.
- Optimize dimensions and file sizes for the rendered area.
- Provide meaningful alt text for informative images.
- The page must remain understandable when autoplay is blocked.
- Do not commit private or confidential media.
- Verify distribution rights before adding or redistributing assets.

Third-party names, logos, artwork, and media are not relicensed by the repository's MIT source-code license. The current source tree does not establish ownership or redistribution permission for every asset. Review provenance and permissions before public or commercial deployment.
